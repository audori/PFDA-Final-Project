## Description
After creating a simple arm rig with a shoulder, elbow, and wrist joint, selecting the shoulder and wrist 
joints create an ik handle with squash and stretch. The code adds locators to each selected joint and measures the distance
between them as you move the arm around to calculate how much the X scale of the joints should increase or decrease. This
program was made to make rigging arms faster and will help me with all the rigs I will be working on this summer and in the future.

Because my code was done in MAYA, I had to use external resources to learn the specific MAYA python commands I neeeded.
All of the information I got was from this link:
